# Ahmad Kurdi — Portfolio

Personal portfolio site. Single-file static HTML — no build step, no dependencies.

**Stack vibes:** React & Laravel developer by day; this site is vanilla HTML/CSS/JS
(canvas particle field, scroll reveals, cursor flare effects, Formspree contact form).

## Run it

Open `index.html` in a browser. That's it.

## Deploy (free, GitHub Pages)

1. Push this repo to GitHub.
2. Settings → Pages → Source: **Deploy from a branch** → `main` / `/ (root)` → Save.
3. Wait a minute — live at `https://<your-username>.github.io/<repo-name>/`.
4. Optional: buy a domain (~$10/yr), point it via Settings → Pages → Custom domain.

## Contact form setup

The form falls back to the visitor's mail app out of the box. For direct-to-inbox
submissions, create a free form at [formspree.io](https://formspree.io) and paste
your endpoint into `FORMSPREE_ENDPOINT` at the bottom of `index.html`.
